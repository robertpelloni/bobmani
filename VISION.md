# VISION: A Unified Rust Architecture for Rhythm Games & Agentic Control

Consolidate Robert Pelloni's rhythm-game ecosystem into a singular, high-performance monorepo engine.
The architecture combines:
1. **Universal Rhythm Engine in Rust**: Porting C++, Java, and Python submodules (`arrowvortex`, `ffr-difficulty-model`, `ddc`, `ddc_onset`, `beatoraja`) into safe, fast Rust.
2. **Consolidated Mission Control Dashboard**: A unified single-page interface categorizing high-value features (Orchestration, Cognitive RAG/AST, System Tray Supervision, Multi-Modal I/O) with context-sensitive tooltips.
3. **Decentralized Gaming & Economy**: Native StepMania/bobmania support with Bobcoin Proof-of-Play, real-time matchmaking, and fitness telemetry.
