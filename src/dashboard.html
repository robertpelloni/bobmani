System tray & supervisor ⓘ

Where is it? pianogame/go/supervisor/ — TraySupervisor tracks 5 engines, handles Ctrl-C/SIGTERM, and QuitAll() gracefully stops all engines and dismisses the tray. It is a console supervisor today: no native OS tray icon library is linked yet, so no icon appears in the Windows tray when run.

Run it: cd pianogame\go; go run . · Quit: Ctrl-C, or call QuitAll(). To quit this Rust server: Ctrl-C in its terminal.
